## 9. 前端设计

十个页面：`/login` · `/`（仪表盘）· `/interviews`（面试记录）· `/bank` · `/bank/private` · `/profile` · `/learn` · `/interview/[id]` · `/report/[id]` · `/trace/[id]`。请求走同源 `/api/*`（`next.config.ts` rewrites → 后端），免 CORS；生产由 nginx 前置接手 `/api`（standalone 下 rewrites 构建期烤死）。

### 9.1 页面要点

| 页面 | 要点 |
| --- | --- |
| 全局导航 | **左侧导航栏**：宽屏 236px、1280px 以下 74px 图标栏、移动端顶部图标条；顶层是平级工具页。面试页使用独立的面试间外壳，报告 / 回放页仍走左栏。未上线页不发出会 404 的链接 |
| 登录与守卫 | 登录页为深色主张面板 + 纸面表单分屏，登录 / 注册同页 tab；`lib/session.ts` 管 token（localStorage 优先 → sessionStorage 降级 → 都禁用则明确提示，不静默失败）；`lib/http.ts` 注入 Bearer 并统一 401 处置；`auth-guard.tsx` 判断完成前先渲染载入态，不闪受保护内容。**401 默认直跳登录页，唯独面试页弹确认再跳**（答到一半被踢走体感太差）；登录接口自身的 401/409 只当表单错误；登录成功统一 `replace("/")` |
| 仪表盘（创建） | 方向固定 + **面试类型** + 题量 5/10/15 + **难度**（自适应 / L1 / L2 / L3）+ **简历（可选，默认收起）**：文件（.pdf/.md/.txt，≤2MB）或粘贴文本。**选行为面后隐藏难度选择器与容量校验**（容量按「难度 × 域配额」算，与行为面题源无关），题量只给 5/10；表单用分段控件，主操作「开始面试」保持在第一屏 |
| 仪表盘（简历区） | 「解析简历」→ 摘要条（「已读到 N 段项目经历 · M 项技能 · 约 K 字」，**解析错当场看得见**，可移除重传；解析态与输入态互斥）+ 一行如实交代「会发送给模型解析；原文与解析结果会保留在服务端以便下次复用，只用于出题与评分」 |
| 仪表盘（历史） | 默认只列最近 5 场（服务端 pageSize=5），右上「全部场次」进面试记录页；进入报告；**每条带物理删除按钮**（确认弹窗后调 DELETE）；行为面场次挂类型徽标且不显示难度；**统计条读接口 counts（全量状态分布），不从列表行里数**；下方给能力快照与按最近报告生成的「下一步」 |
| 面试记录页 | 全量场次列表：复用仪表盘同一列表组件，服务端分页 + 过滤（状态 / 类型 / 时间），工具条 +「共 N 场 / 第 x / y 页」；改过滤回第一页、删到空页回退一页、空结果与「还没有记录」文案分开；行内续面 / 报告 / 删除口径不变；页头由页面提供 |
| 题库页 | **筛选 / 结果 / 详情三栏**：搜索框（关键词走混合检索，提交后与筛选叠加）+ 域列表 + 难度分段 + 厂商/面次下拉；结果行选中后右侧看详情，窄屏改为行内展开。详情含参考答案 / 关键点 / **来源合规四要素**（主源标注、`原文` 外链 `rel=noreferrer`）+ 分页。卡头按模式切换文案：「按相关性排序 · 最多 20 条」（search，无 total）vs「共 N 题 · 第 x/y 页」（browse）。**筛选或搜索任一项变更即回第一页**（判据在 `lib/bank.ts` 的 `withFilter`，vitest 钉死） |
| 私有题库页 | 上传卡（模板说明前置）→ 结果条给**三份明细**（导入 / 重复 / 失败，重复写明「未覆盖」——答案可能已被他手改过）→ 列表筛选 + **行内展开**编辑 / 归档恢复。后端 `enabled`/`draft` 在前端读作「使用中 / 已归档」 |
| 容量校验 | 挂载时拉一次 `/api/bank/capacity`（题量 × 4 难度一次拿全，切换难度零网络）。直供不足的题量**禁用 + 明写缺在哪**（不做静默禁用——禁了不说原因，用户只会以为页面坏了）；**拉取失败一律不禁用**（`capacity = null`）：服务端本就不拦创建，网络抖动不能让表单把用户锁死 |
| 报告页 | 页头动作 + 三格统计条；五维雷达 + 知识域横向条形（短板域用警示色**并附文字标注**，不靠颜色单独表意）+ 逐题点评卡 + 短板高亮 + 总评。**逐题复盘卡**：我的回答按「【追问补充】」分成「首答 / 追问补充 N」、五维得分、关键点 ✓/✗、题库题参考答案折叠（项目深挖题无权威答案，只给关键点对比）；历史报告缺字段则退化为「题干 + 点评」。三处入口：决策回放 · 导出 PDF（文件名纯逻辑在 `lib/download.ts`）· 针对性练习推荐（`?interview=<id>` 承接来源场次，`showAdvice=false` 避免与学习建议复述；行为面不渲染） |
| 学习推荐页 | 左栏来源场次 / 短板域 / 训练建议，右栏按短板域分组的资料卡；场次选择器只列技术面；与报告页共用 `recommend-groups.tsx`，默认场次判定在 `lib/learn.ts` |
| 能力档案页 | 统计条 + 五维雷达/表格 + 总分曲线（两列）+ 知识域热力图 + 短板变化；窗口、色阶与空态口径见 §4.11 |
| 决策回放页 | **节点时间线**在逐轮卡片之上（§4.7）；其下是只读事件时间线，按 `round` 聚成逐轮卡片——出题信息进卡片头，评分 / 追问 / 换题 / 结束被挽留按序排，`round=null` 的收尾事件单列。**规则与原因由后端给，前端只映射文案、不重算决策**（重算就可能与当时不一致）；旧场次无事件流 → 空态提示。静态展示不做自动播放，入口仅报告页 |

### 9.2 面试页

- **SSE 走 POST**：`EventSource` 只支持 GET → `lib/sse.ts` 用 `fetch` + 手动分帧，兼容心跳注释与中文跨 chunk 截断。
- **流式渲染 + 打字机兜底**（`lib/stream-render.ts` 的 `StreamBuffer`）：`delta_start` 开气泡 → `delta_chunk` 追加给最近一条未结算消息 → `delta` 按序 FIFO **用终稿替换**累积文本（服务端会 strip 两侧空白，分片拼接可能与终稿差几个不可见字符，以终稿为准、前端不二次拼接）。旧打字机（`TypewriterQueue`）只剩两条路：无分片的消息走它逐字吐、未注册事件名静默丢弃。**未结算气泡在错误或流结束时收走**（没终稿 = 从未落 checkpoint，留着就是「看得见、刷新就没」的假消息）。
- **刷新恢复**：刷新后从 checkpoint 重建消息列表；网络失败 / HTTP 4xx / 流内 `error` 都转中文文案 + 重试按钮，**判据由服务端 `stalled` 给**（`lib/recovery.ts` 纯函数分两路），重试不重复插入消息。已结束场次进只读回放（隐藏输入框、顶部操作区换「查看报告」，报告页与回放页互链）。**输入框草稿**按场次存 localStorage（`marda.draft.{interviewId}`，只存文本、不落服务端），会话加载成功后恢复；发送成功、场次结束 / 只读、删除场次时清除；存储不可用时静默降级。
- **输入体验**：Enter 发送、Shift+Enter 换行（输入法「上屏回车」不误发送）；**随内容自增长、初始 2 行、封顶 6 行**（`fitInput()` 读 CSS 的 `maxHeight` 当唯一上限来源，超了框内滚动）。
- **语音作答**：点击开始、再点结束；录音期间**禁用发送与结束面试**、开麦即停播。转写实时落输入框、**不自动发送**；一个字都没转出来给「没有听清」提示。**语音播报**为面试间顶部开关（默认关、localStorage 记忆），开启后终稿自动播报、先播当前这道题；播报失败只提示一次。**权限被拒 / 服务不可用一律降级回文字**。

### 9.3 面试间与控制条（`components/interview-room.tsx`）

**≥xl 是三栏面试间**：左 264px 会话与阶段栏（品牌 / 岗位 / 进度 / 阶段时间线 / 结束），中间对话时间线（max-width 720），右 320px 舞台（面试官与候选人 tile、会话信号、答题提示）；三栏各自滚动，输入区固定在中间列底部。**面试间默认亮场，可切暗场**（`.room-dark` 覆盖 `--room-*` 令牌，偏好写 `localStorage["marda.room.theme"]`）；暗场不跟随系统，工作台主题仍跟随系统。

**<xl 回落为固定顶部操作条 + 顶部舞台卡 + 对话 + 控制台**：舞台卡仍是同一对 tile 的另一个安置点（`max-w-[496px]`、1px 描边、无阴影）；窄屏顶部操作条固定，内容区预留高度。

两个安置点里都是**两个等大的 tile**：面试官（monogram 人像框 + 状态徽标）与「我」（摄像头画面，关闭时同尺寸占位 + 「开启摄像头」入口——对等感不塌）。状态徽标由现有状态派生（`lib/interview-room.ts` 的 `interviewerChip`，vitest 钉优先级：已结束 > 播报 > 聆听 > 思考 > 回应 > 等待）——**不引入新会话状态、不新增后端字段**。

- **摄像头 = UI 模拟**：**帧不上传、不落库、AI 不看**——全仓画面只有 `getUserMedia → video.srcObject` 一条路；**轨道收摊是单一出口 `stopStream`**（关闭 / 离开页面 / 面试结束三处共用，漏一处摄像头灯就常亮）；「我」tile 角标如实交代（「仅本机可见，不上传」）；**权限被拒 / 无设备 / 被占用按 DOMException 分流文案**（`lib/camera.ts` 的 `cameraErrorMessage`），失败**不改偏好**。**默认关；localStorage 只记住「上次开过」用于按钮提示（「恢复摄像头」），不在页面加载时自动取流**——Safari 无用户手势调用 `getUserMedia` 会每次弹权限框；只读回放与已结束场次不恢复；取流约束用 ideal 不用 exact、`audio` 显式 false。
- **控制条**在输入区（语音作答 / 摄像头 / 附截图 ｜ 发送，激活态 = filled）；容器 `flex-wrap`，窄屏整组换行、不把按钮压变形。
- **状态 Tab**：当前题、阶段 / 进度、语音 / 摄像头开关，以及 **系统语音选择器**（edge-tts 降级时使用；偏好存 `localStorage["marda.ttsVoice"]`）；只读场次不显示语音开关。

### 9.4 设计系统与窄屏

- **设计令牌**：暖灰纸面 / 深色左栏 / 单一钴蓝强调色（`globals.css`，含 `--success`、`--stage` 与面试间 `--room-*`）+ 中文回退字体栈（Geist 不含 CJK）+ 全局 `prefers-reduced-motion` 兜底；工作台跟随系统明暗，面试间独立亮 / 暗切换（默认亮场，localStorage 记忆）。克制配色、强排版、微动效，专注型对话布局，不做营销首页。
- **状态态各有唯一档位**：空态 / 加载态两档 / 错误态三档（可重试 = inline + 按钮、表单级 = 一行红字、全页 = 中性色 + 返回首页）。
- **卡片材质两档**：面板 = `rounded-xl + 1px border`（表头带分隔线，无阴影、无 ring），内嵌面板 = `rounded-lg border + bg-muted/30`。共享件：`AppRail` / `PageShell` / `PageHeader` / `MonoLabel` / `StatStrip` / `Segmented` / `EmptyState` / `ErrorState` / `StatusBanner` / `InlinePanel`。
- **窄屏导航**：移动端固定顶部图标条（56px），内容区预留 76px 顶部偏移；左栏在 1280px 以下折叠为 74px 图标栏，题库详情栏在 1280px 以下改为行内展开，面试间右侧舞台在 1280px 以下收回顶部卡片。验收 = 500px 视口截图（登录 / 仪表盘 / 题库 / 面试间）；320px 未覆盖。

### 9.5 代码工作台与表达复盘（M15/M16）

- **代码工作台**：右栏「状态 / 白板 / 代码」三 Tab 全部就绪；代码 Tab 与窄屏顶栏按钮打开全屏覆盖层（`CodeWorkbench`），与白板互斥、首次打开后保持挂载（**回放/已结束场次也可独立练习**，代码不写本场记录）。Monaco 懒加载、同源 `/monaco/vs`；左侧题面卡（标题 / 描述 / 示例 / 约束）+ 语言 + 编辑器，右侧点评面板（问题 / 具体反例 / 复杂度 / 面试官追问 + 追问输入）；代码改动后旧点评标「已过期」。**生产构建不含 Monaco 包体**（首开才加载静态资源）。
- **表达复盘**：报告页在统计条之后渲染 `ExpressionCard`（语音时长 / 平均语速 / 长停顿 / 口头禅 + 限制说明），**不依赖 `hasScores`**；逐题复盘卡加一行「语音作答 / 语速 / 长停顿 / 口头禅（段数）」。PDF 用同一 payload 的「表达复盘」卡与逐题行。
- **刷新恢复**：打开的工作台面板写页面 URL `?panel=code|board`；代码工作台快照（题目 / 语言 / 代码 / 点评 / 追问）与白板场景（Excalidraw `serializeAsJSON`）按场次存 localStorage，刷新后回到原工作台且内容还在。只读/已结束场次白板不开（它会提交消息），代码工作台可开；快照格式坏了整份丢弃、重新抽题，不炸工作台。
