## 贯穿全程的四条做法

1. **真数据验证**：能在真实数据副本上验收，就不只在隔离环境自证。
2. **机械判据**：用断言、重合率、CDP 请求计数、像素采样证明结论，不靠肉眼。
3. **单一来源**：同一业务数字只保留一份实现与一处口径，测试钉死。
4. **诚实边界**：未覆盖的写明未覆盖；降级如实标注；缺数据不补零。
